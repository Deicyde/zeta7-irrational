## Finding 1: (53) is false as written, the estimate is not

Exact rational computation for `n = 1` (`K = 40`, `N = 3`, `h = 37`),
building `G_K` exactly as `Gentry` does (polynomial part
`Rnum div Dtail`, residues `Rnum(-a^2)/Dtail'(-a^2)`, values `muMonomial`
and `muPole`), at every prime satisfying (52), `p in {17,19,23,29,31,37}`:

- Paper's modification `mu_0(t^e) = mu(t^e) - c_e/p` (`c_e = 0` for
  `e < 3p-4`, `c_e = p mu(t^e) mod p` otherwise; pole values unchanged)
  gives `G_K = A + p^{-1} L` with `L` integral, but `A` is not integral
  in the monomial basis: `min v_p` of the `X`-free coefficients of `A`
  is `-10` (p=17), `-9` (p=19,23,29,31), `-1` (p=37), attained already
  at `i + j = 0`. The `X`-coefficients are integral. Cause: the pole
  values `j^6 H7_j` for `p <= j`, `p` not dividing `j`, have `v_p = -7`,
  and single residues can have `v_p = -(l-1)`.
- Rank bound (54) holds: `rank L = 10 <= r_p = 11` (p=17),
  `4 <= 5` (p=19), `L = 0` for `p >= 23`.
- The proposition itself holds and is sharp: exact `Delta_K(X)`
  (degree 37, leading coefficient matches (10)) has
  `v^G_p(Delta_K) = -138, -123, -130, -76, -58, -4` against
  `gamma^out_p = -146, -129, -130, -76, -58, -4` for
  `p = 17, 19, 23, 29, 31, 37`. For `p > K` no prime above 37 divides
  any coefficient (checked to 400).

Polynomial moments below `3p - 4` are `p`-integral at all these primes,
as the paper says.

## Finding 2: the route that works (class basis, weighted hypothesis)

The integrality the proof needs holds in the class basis, with weights,
not for `A` itself. Rows, for each class `1 <= c <= m = (p-1)/2`:
`S_c = {N < j <= K : j = +-c mod p}`, `F_c = prod_{j in S_c} (t + j^2)`,
`E_c = prod_{j in S_c, j > p} (t + j^2)` (degree `l - 2`),
`P_c = prod_{d != c} F_d` (over `d = 0..m`, `S_0` = multiples of `p` in
`(N, K]`), rows `P_c q_{c,i}` with the paper's `q_{c,i}` for
`0 <= i < l - delta`, and zero-class rows `P_0 t^i`, `i < |S_0|`.
The row count is exactly `h = K - N`. Then, for `n = 1..5` and every
prime satisfying (52) (88 cases):

- the basis is `Z_p`-unimodular (determinant nonzero mod `p`; mod `p`
  it is the CRT basis for the coprime factors `(t + c^2)^{|S_c|}`);
- the modified Gram matrix `A' = mu_0(r s D_N^7/Dtail)` satisfies
  `v_p(A'_{rs}) >= w_r + w_s` with the outer weights (56) on ordinary
  rows, both `X`-coefficients, no exceptions;
- zero-class rows need doubled weight `-1` when `K < 2p` (one row) and
  `(-3, 0)` when `K >= 2p` (rows `P_0`, `P_0 t`);
- the zero-weight count `z` equals the formula's (`p - 1 - N + u` for
  `K < 2p`, `p + u` for `K >= 2p`), and
  `sum w - min(r_p, z)` (doubled weights) equals `gamma^out_p` exactly
  when `K < 2p` and exceeds it by 3 when `K >= 2p` (by 4 at `n=1,p=17`).

So the rank lemma applied in this basis proves (59). Cross-class
entries are pure polynomial moments; within a class, rows with index
`>= l - 2` contain `E_c`, which cancels the poles above `p`, and the
two remaining values at `c`, `p - c` are integral and congruent mod `p`
(`H7_{p-c} = H7_{c-1} mod p` because `sum_{v<p} v^{-7} = 0 mod p`);
for `i, j < l - 2` the residue at `j' in S_c` has valuation
`>= (i+j) + 7 delta - (l - delta - 1) - 7`, which is the paper's
`i + j + 8 delta - l - 6`.

## Finding 3: `p > K` holds in the monomial basis

For `p > K` every entry `Gentry n i j` already has `p`-integral
coefficients (checked `n = 1,2,3`, all primes `K < p < 6K`), but single
residues have `v_p = -1`: poles `a` and `p - a` (both in `(N, K]`) must
be paired. Proof: the polynomial part has integer coefficients and
degree `<= 7N + 2h - 2 < 3p - 4`; for unpaired `a`, `Dtail'(-a^2)` is a
`p`-unit; for a pair, `res_a + res_{p-a} = (x_a - x_{p-a})/((p-2a)p)`
with `x_a = Rnum(-a^2)/prod_{c != a, p-a}(c^2 - a^2)` congruent to
`x_{p-a}` mod `p`, and `muPole a = muPole (p-a)` mod `p`.

## Proposed decomposition

1. Outer moments and decomposition: `mu(t^e)` `p`-integral for
   `e < 3p-4`, `L` integral of rank `<= r_p` (54).
2. Large primes: `p > K` gives `v^G_p(Delta_K) >= 0` (Finding 3).
3. Class basis: definition and `Z_p`-unimodularity.
4. Entry valuations: `v_p(A'_{rs}) >= w_r + w_s` with (56) and the
   zero-class weights of Finding 2.
5. Gauss-valuation rank lemma: from `ZetaSeven.rank_lemma` by expanding
   `det(alpha + X beta + p^{-1}L)` row-wise (`MultilinearMap.map_add_univ`):
   each `X^k` coefficient is a sum of determinants of mixed matrices
   `alpha/beta + p^{-1}(L with the beta rows zeroed)`, to which the
   rational rank lemma applies.
6. Weight sum: `sum w - min(r_p, z) >= gamma^out_p` from the class
   counts `l_K(a)`.
7. Assembly (this article).

zero-class rows and weights, and the derivation of (59) to [5]; the

## Evidence

Exact rational computation for `n = 1` (`K = 40`, `N = 3`, `h = 37`),
building `G_K` exactly as `Gentry` does (polynomial part
`Rnum div Dtail`, residues `Rnum(-a^2)/Dtail'(-a^2)`, values
`muMonomial` and `muPole`), at every prime satisfying (52),
`p in {17,19,23,29,31,37}`:

- The modification `mu_0(t^e) = mu(t^e) - c_e/p` (`c_e = 0` for
  `e < 3p-4`, `c_e = p mu(t^e) mod p` otherwise; pole values unchanged)
  gives `G_K = A + p^{-1} L` with `L` integral.
- `A` is not integral in the monomial basis, which is why the article
  claims nothing about it: `min v_p` of the `X`-free coefficients of
  `A` is `-10` (p=17), `-9` (p=19,23,29,31), `-1` (p=37), attained
  already at `i + j = 0`. The `X`-coefficients are integral. Cause: the
  pole values `j^6 H7_j` for `p <= j`, `p` not dividing `j`, have
  `v_p = -7`, and single residues can have `v_p = -(l-1)`.
- Rank bound (54) holds: `rank L = 10 <= r_p = 11` (p=17),
  `4 <= 5` (p=19), `L = 0` for `p >= 23`. The exact count of nonzero
  rows is `max(0, 2h - T - 1)`; (54)'s `2h - T` is one more, which is
  harmless.

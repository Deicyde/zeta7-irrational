## Evidence

For `p > K` every entry `Gentry n i j` already has `p`-integral
coefficients (checked `n = 1,2,3`, all primes `K < p < 6K`), but single
residues have `v_p = -1`: poles `a` and `p - a` (both in `(N, K]`) must
be paired. Rechecked 2026-10-18 at `n = 1`, `p = 41`, `a = 4, 10, 20`,
`i + j = 0, 5`: each residue has `v_41 = -1`, the pair sum `v_41 = 0`.
So the paper's sentence "the residues are `p`-integral" is false as
written, while the conclusion holds. For `p > K` no prime above 37
divides any coefficient of the exact `Delta_K(X)` at `n = 1` (checked
to 400).

Proof route: the polynomial part has integer coefficients and degree
`<= 7N + h - 2 < 3p - 4`; for unpaired `a`, `Dtail'(-a^2)` is a
`p`-unit; for a pair, `res_a + res_{p-a} = (x_a - x_{p-a})/((p-2a)p)`
with `x_a = Rnum(-a^2)/prod_{c != a, p-a}(c^2 - a^2)` congruent to
`x_{p-a}` mod `p`, and `muPole a = muPole (p-a)` mod `p` (both equal
`a^6 (X - H7_{a-1}) - 1/(2a) - 1/6` mod `p`, from
`H7_{p-a} = H7_{a-1} mod p`).

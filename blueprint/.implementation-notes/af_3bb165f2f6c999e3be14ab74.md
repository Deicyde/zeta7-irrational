## Evidence

With the class basis and the modified Gram matrix
`A' = mu_0(r s D_N^7/Dtail)`, exact computation for `n = 1..5` and every
prime satisfying (52) (88 cases) gives `v_p(A'_{rs}) >= w_r + w_s` with
the outer weights (56) on ordinary rows, for both `X`-coefficients, no
exceptions. Zero-class rows need doubled weight `-1` when `K < 2p` (one
row) and `(-3, 0)` when `K >= 2p` (rows `P_0`, `P_0 t`). These weights
were found by the computation, not read from the paper.

Cross-class entries are pure polynomial moments; within a class, rows
with index `>= l - 2` contain `E_c`, which cancels the poles above `p`,
and the two remaining values at `c`, `p - c` are integral and congruent
mod `p` (`H7_{p-c} = H7_{c-1} mod p` because `sum_{v<p} v^{-7} = 0 mod p`);
for `i, j < l - 2` the residue at `j' in S_c` has valuation
`>= (i+j) + 7 delta - (l - delta - 1)`, and the pole value adds `-7`,
which is the paper's `i + j + 8 delta - l - 6`. The derivative factors
have valuation exactly one because `j + j' <= 2K < p^2`, which is where
(52)'s `p^2 > 2K` enters.

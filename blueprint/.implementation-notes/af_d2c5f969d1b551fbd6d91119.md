## Evidence

were found by the entry-valuation computation, not read from the
paper: zero-class rows need doubled weight `-1` when `K < 2p` (one

## Lean hints

Keep the family doubled, like `outerWeightDbl` (twice (56), the
convention of `ZetaSeven.rank_lemma`, on branch
`formalize/outer-estimate` at `0f0a541`), so it is integer-valued:

class gets `-1` (`K < 2p`) or `-3, 0` (`K >= 2p`). A `Finset (ℕ × ℕ)`
or a sigma type over `c ∈ Icc 0 m` works as the index set. The rank
lemma takes weights on `Fin h`; the bijection between this index set
and the `h` rows is the row count of the outer class basis, so the
outer estimate composes the two, while the weight sum only needs the
family itself.

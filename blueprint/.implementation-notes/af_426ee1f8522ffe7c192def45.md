## Evidence

- Exact rational computation at `n = 1`, `p = 41` (from the
  large-prime check): for `a = 4, 10, 20` and `i + j = 0, 5`, each
  residue of `D_N^7 t^{i+j}/Dtail` at `-a^2` and `-(p-a)^2` has
  `v_41 = -1`, while each pair sum of residues and each pair
  contribution to the entry has `v_41 = 0`. This is source-map
  erratum 7.
- Generic check (2026-10-18, exact rationals): for every prime
  `7 <= p <= 43` and every `1 <= a <= (p-1)/2`, `muPole a` and
  `muPole (p-a)` are `p`-integral and congruent mod `p`, and
  `H7 (p-a) = H7 (a-1)` mod `p`; for 650 random instances of part 2
  (`S` = `{a, p-a}` plus up to four other positive integers below
  `3p` not congruent to `±a`, `Q` with coefficients of denominator
  1, 2 or 3), both residues have `v_p >= -1`, the residue sum and the
  pair contribution are `p`-integral, and in the 618 instances with
  `Q(-a^2)` a `p`-unit each residue has `v_p = -1` exactly.
- Mod `p`, both pole values equal
  `a^6 (X - H7_{a-1}) - 1/(2a) - 1/6`.

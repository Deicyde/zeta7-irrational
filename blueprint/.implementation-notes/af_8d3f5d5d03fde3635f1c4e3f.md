## Evidence

The rows were reconstructed (the paper names only `q_{a,i}`) and checked
by exact computation for `n = 1..5` and every prime satisfying (52)
(88 cases): the row count is exactly `h = K - N`, and the basis is
`Z_p`-unimodular (determinant nonzero mod `p`; mod `p` it is the CRT
basis for the coprime factors `(t + c^2)^{|S_c|}`).

Under (52), `|S_0| = floor(K/p)` is 1 or 2, and `l_K(c) <= 6`.

The zero-class weights (moved here from the outer range data node on
2026-10-18) were found by the entry-valuation computation, not read from
the paper: zero-class rows need doubled weight `-1` when `K < 2p` (one
row) and `(-3, 0)` when `K >= 2p` (rows `P_0`, `P_0 t`). Keep them
doubled in Lean, like `outerWeightDbl` (twice (56), the convention of
`ZetaSeven.rank_lemma`, on branch `formalize/outer-estimate`), so the
weight family is integer-valued.

## Lean hints

transition matrix to `ZMod p` and show the reduced rows are linearly
independent, using pairwise coprimality of `X + C (c^2)` for distinct
squares and the triangular shape inside each CRT factor. No Mathlib

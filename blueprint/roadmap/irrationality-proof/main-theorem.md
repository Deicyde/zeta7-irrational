# Zeta 7 is irrational

The number `ζ(7)` is irrational.

If `ζ(7) = a/b`, then `b^{37n} Q_{40n,200}(a/b)` is a positive
integer, but the decay estimate bounds it above by
`exp(37n log b - 19000n^2)`, which drops below 1 for large `n`:
impossible. This is the terminal node of the DAG.

# Local range data

For a prime `p` put (42) `m = (p-1)/2`, `m_N = ⌊N/p⌋`, and
`m_K = ⌊K/p⌋`, and for `A ≥ 0` and `1 ≤ a ≤ m` define the class
count (43)
`ℓ_A(a) = #{1 ≤ j ≤ A : j ≡ a or j ≡ -a (mod p)}`.
These are shared by the inner and outer ranges.

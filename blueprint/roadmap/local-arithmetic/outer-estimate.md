# Outer range estimate

In the outer range `K/3 < p ≤ 2h`, the determinant valuation
bound `v^G_p(Δ_K) ≥ γ^out_p`, with the rank correction `r_p`,
outer weights, and removed-class costs as stated; for `p > K`
the determinant is `p`-integral.

The proof shows polynomial moments are `p`-integral below
`3p-4` (von Staudt-Clausen plus the divisibility offset),
splits `G_K = A + p^{-1}L` with the rank bound on `L`, builds
the unimodular basis with class rows, and applies the rank
lemma to the outer weights.

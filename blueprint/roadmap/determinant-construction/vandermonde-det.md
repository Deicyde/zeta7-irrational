# Vandermonde determinant

The determinant of a Vandermonde matrix vanishes exactly when two
nodes coincide. This is upstream as
`Matrix.det_vandermonde_eq_zero_iff` in the pinned Mathlib checkout
(`Mathlib/LinearAlgebra/Vandermonde.lean`), verified by inspection;
no project proof is needed.

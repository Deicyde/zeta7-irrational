# Functional mu

Fix the paper's parameters `K = 40n`, `N = 3n`, `h = 37n`,
`α = 3/40`, `λ = 37/40`, `H = 49/40`, the divisor polynomials
`D_m(t) = ∏_{j=1}^m (t + j^2)`, the partial sums `H^(7)_j`, and the
Bernoulli numbers, then define the `ℚ`-linear functional `μ_X` on
rational functions with only simple poles among the negative integer
squares by its values on monomials (Bernoulli term, independent of
`X`) and on simple poles `1/(t + j^2)` (affine in `X`), extended by
polynomial division and partial fractions.
